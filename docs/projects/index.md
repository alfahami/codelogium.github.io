<span class="home-eyebrow">Blockchain</span>
<div class="grid cards" markdown>

-   :lucide-graduation-cap:{ .lg .middle } __bcertificate__

    ---

    A permissioned blockchain network built on Hyperledger Fabric for issuing and verifying academic transcripts. Institutions can enroll, issue certificates as on-chain assets, and any third party can verify authenticity without contacting the issuing body.

    ---

    [View project :lucide-arrow-right:](blockchain/bcertificate/)

-   :lucide-map:{ .lg .middle } __landcertificate__

    ---

    A Hyperledger Fabric network for recording and transferring land ownership. Property titles are stored as blockchain assets, making ownership history tamper-proof and publicly verifiable. Built as a proof of concept for land registry modernization.

    ---

    [View project :lucide-arrow-right:](blockchain/landcertificate/)

</div>

<div class="project-section" markdown id="fullstack">

<span class="home-eyebrow">Full Stack &amp; Microservices</span>
<div class="grid cards" markdown>

-   :lucide-wallet:{ .lg .middle } __Crypto Portfolio__

    ---

    A Spring Boot microservices application for tracking cryptocurrency holdings. Services communicate over REST, with a gateway handling routing and auth. Built to practice service decomposition, inter-service calls, and distributed state management.

    ---

    [View project :lucide-arrow-right:](java/crypto-portfolio/)

-   :lucide-life-buoy:{ .lg .middle } __IT Support Ticket System__

    ---

    A full stack ticket management system built with Spring Boot and a React frontend. Users can open, track and escalate support requests; agents can assign, update and close tickets. Covers role-based access, pagination, and real-time status updates.

    ---

    [View project :lucide-arrow-right:](java/it-support-ticket-system/)

-   :lucide-presentation:{ .lg .middle } __Conferences__

    ---

    A conference management platform built with Spring Boot. Organizers can create events, manage committees, schedule sessions and assign speakers. Built to practice domain modeling, REST API design, and multi-role authorization in a real-world-shaped problem.

    ---

    [View project :lucide-arrow-right:](java/conferences/)

-   :lucide-pill:{ .lg .middle } __Pharmacy Management__

    ---

    A JEE web application for managing pharmacy inventory, prescriptions, and sales. Built during a university module to learn the Java EE stack end to end: servlets, JPA, and deployment on a local application server.

    ---

    [View project :lucide-arrow-right:](java/pharmacy-mgmt/)

-   :lucide-users:{ .lg .middle } __acemanager__

    ---

    A membership management application for a Comorian student association. Members can register, pay dues, and access resources; admins manage rosters and events. Built with Node.js and a simple dashboard. My first production-grade JavaScript backend.

    ---

    [View project :lucide-arrow-right:](web/acemanager/)

</div>
