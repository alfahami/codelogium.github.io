    ---

    A permissioned blockchain network built on Hyperledger Fabric for issuing and verifying academic transcripts. Institutions can enroll, issue certificates as on-chain assets, and any third party can verify authenticity without contacting the issuing body.

-   :lucide-map:{ .lg .middle } __LandCertificate__

    ---

    A Hyperledger Fabric network for recording and transferring land ownership. Property titles are stored as blockchain assets, making ownership history tamper-proof and publicly verifiable. Built as a proof of concept for land registry modernization.
